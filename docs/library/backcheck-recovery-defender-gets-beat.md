# Backcheck Recovery: Defender Gets Beat

## Teaching Point

Backchecking support changes when the first defender gets beat.

If the teammate who had the puck carrier loses that lane, the backchecker may need to become the next defender.

## Main Cue

First defender gets beat.

## Correct Read

Protect inside and become the next defender.

## Common Mistake

Continuing to cover support while the puck carrier becomes the immediate danger.
