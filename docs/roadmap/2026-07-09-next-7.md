content factory second; make the new engine visible to players third; then

is DONE and factory-gated as of 2026-07-09.

## 2. Run the manual playtest gate (10 minutes)

Checklist: `docs/manual-playtest/question-kinds-cycle1.md`. Play the three
proof plays at U11/U13 plus the regression spot-checks, and make the two

- predict-next: keep or neutralize the red wrong-button flash before the truth plays

spot-mistake needs a second pass (see item 5).

with the age band from the player profile. This is a small spec -> plan ->
build cycle; do it before mass-producing content so real kids see the kinds
early.

## 4. Bulk batch 002 through the kind-aware factory

`npm run report:next-variants` now recommends a kind per family (verdict is

## 5. Spot-mistake playtest #2 -> open its factory gate

After batch 002 lands, run the second clean playtest of the spot-mistake
kind (One Defensible Mistake Rule requires two). From then on all five kinds

## 6. Cycle 2: Daily Faceoff (arcade shell v1)

Spec -> plan -> build the first game mode from the research doc: 5 curated
reads/day per band, calendar streak, earned "Backup Goalie" streak
protection (never purchasable, "paused" never "lost"), milestone
celebrations at 3/7/14/30. Session wrapper over the existing catalog, no new
rink primitives. This is the daily-habit engine the beta needs once content
depth exists.

## 7. Parent/coach weekly progress card v1

The retention lever that pays: days played, accuracy by concept/family,
streak state, printable milestone badges. Telemetry is already kind-aware
(judge/justify split, per-family error concentration), so the data exists;
this is a rendering + delivery task. Ships alongside or right after Daily
Faceoff so the streak has an adult witness.
