# RinkReads Cognitive Gym

Eleven procedurally generated, hockey-native brain-training drills inspired by
the Hockey IntelliGym approach. Zero content maintenance. Every rep is
generated by code.

## Drills

| Drill id | Player-facing name | Skill | Format |
| --- | --- | --- | --- |
| anticipation | Read the Pass | Anticipation | 8 reps, tap where the hidden puck crosses the line |
| tracking | Baylor's Pick | Awareness | 6 shifts, track 3 teammates among 5-16 skaters |
| reaction | Shoot or Hold | Reaction | 16 shots, tap blue / hold orange, audible go cue |
| eyesup | Eyes Up | Vision | 12 flashes, eyes on the center puck, tap the peripheral flash |
| snapshot | Snapshot | Memory | 8 reps, one glance, tap where the open teammate was |
| findlane | Find the Lane | Vision | 8 reps, hit the one open passing lane before it closes |
| bestoption | Best Option | Decisions | 8 frozen reads, shoot / pass / carry before the clock |
| readnumbers | Read the Numbers | Vision | 10 reps, read a jersey number off a streaking skater |
| lateread | Late Read | Adapting | 9 reps, switch the pass when a defender steps up late |
| twothings | Two Things at Once | Focus | 9 reps, tap the crossing puck AND the flashed cue |
| shootout | Pick Your Spot | Shot Read | 10 shots, hit the open part of the net before it closes |

All drills share one adaptive engine: 3 consecutive successes moves the level
up, 2 consecutive failures moves it down. Levels run 1-20 and persist per
player per drill. Every drill scores on the same graded 0-1000-per-rep scale
(`gymPoints.gradedPoints`; Reaction grades by reaction time via
`reactionCore.js`, Tracking by targets held via `trackingCore.js`). No drill
can produce a negative session total.

## Phase 1 modules (2026-07-09)

- `gymBand.js` resolves the app's division strings ("U11 / Atom") to band keys
  and drives the age-seeded starting levels (U7:2, U9:4, U11:6, U13:7,
  U15/U18:8).
- `gymAudio.js` synthesizes all audio cues with WebAudio (no sound files) and
  owns the mute preference and reward haptics. `gymCueHooks()` plugs rep and
  level-up cues into the adaptive engine.
- `gymFx.jsx` provides the results-card celebration (`ScoreCount` count-up,
  `ConfettiBurst`); `gymProgressCore.sessionRankLabel` powers the
  "Personal best!" / "Top 5 session" tags.
- Miss distances are reported in real rink feet (200ft x 85ft mapping), never
  pixels.

## Install

The hub is mounted from `App.jsx`:

```jsx
import CognitiveGym from './cognitive-gym/CognitiveGym';

<CognitiveGym playerId={player.id} ageBand={player?.level || null} onBack={...} />
```

`ageBand` accepts the raw `player.level` division string; resolution happens
inside. No new dependencies. React 17+ with hooks, plain canvas, plain CSS.

## Storage

Local-only via `localStorage`:

- `rinkreads_gym_v1` — all drill records:
  `{ [playerId]: { [drillId]: { level, streak, best, bestPoints, sessions: [{date, score, points, level, meta}] } } }`
- `rinkreads_gym_unit` — "ft" | "m" distance readout preference
- `rinkreads_gym_muted` — "1" | "0" audio mute

`gymStorage.js` is the only file that touches storage. When you resume the
Supabase backend, replace its exported functions with async versions and the
drills need only minor await changes.

## Theming

All colors live as CSS variables at the top of `cognitive-gym.css`
(`--gym-bg`, `--gym-gold`, etc). Edit that one block to match RinkReads brand.

## Tuning difficulty

Each drill maps level (1-20) to parameters with `lerp(easy, hard, levelT(level))`
in its `*Core.js` file (or the drill component for the older three). Rep counts
are the `ROUNDS` / `TRIALS` / `REPS` / `SHIFTS` constants at the top of each
drill file.

## Marketing language guardrail

Describe these as cognitive drills inspired by sports-science research on
anticipation, awareness, and reaction training. Do not cite IntelliGym's
study results (42% PPG, injury reduction) as outcomes of RinkReads; those
findings apply to their validated protocol, not this implementation.
