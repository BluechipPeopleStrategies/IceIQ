# RinkReads Cognitive Gym

Three procedurally generated brain-training drills modeled on the Hockey
IntelliGym approach: anticipation, multi-object tracking (awareness), and
go/no-go reaction. Zero content maintenance. Every rep is generated by code.

## Drills

| Drill | Player-facing name | Skill | Format |
|---|---|---|---|
| Anticipation | Read the Pass | Trajectory prediction | 8 reps, tap where the hidden puck crosses the line |
| Tracking (MOT) | Head on a Swivel | Divided attention / awareness | 6 shifts, track 3 teammates among 6-10 skaters |
| Go/No-Go | Green Light | Reaction time + inhibition | 16 shots, tap green / hold red |

All three share one adaptive engine: 3 consecutive successes moves the level
up, 2 consecutive failures moves it down. Levels run 1-20 and persist per
player per drill.

## Install

1. Copy the `cognitive-gym/` folder into `src/`.
2. Add a route (or view state) for the hub:

```jsx
import CognitiveGym from './cognitive-gym/CognitiveGym';

// In your router or view switch:
<CognitiveGym playerId={activePlayerId} />
```

3. Pass your existing device-level player profile ID as `playerId`. If the
   app has no profile selected, omit it; everything stores under `default`.

No new dependencies. React 17+ with hooks, plain canvas, plain CSS.

## Storage

Local-only via `localStorage` under one key: `rinkreads_gym_v1`.

Shape:

```
{ [playerId]: { [drillId]: { level, best, sessions: [{date, score, level, meta}] } } }
```

`gymStorage.js` is the only file that touches storage. When you resume the
Supabase backend, replace its four exported functions with async versions
and the drills need only minor await changes.

## Theming

All colors live as CSS variables at the top of `cognitive-gym.css`
(`--gym-bg`, `--gym-gold`, etc). Edit that one block to match RinkReads brand.

## Tuning difficulty

Each drill maps level (1-20) to parameters with `lerp(easy, hard, levelT(level))`:

- `AnticipationDrill.jsx` > `buildTrajectory()`: speed, hide point, tolerance, launch angle
- `TrackingDrill.jsx` > `makeDots()`: skater count, speed, tracking duration
- `ReactionDrill.jsx` > `startTrial()`: response window, no-go probability

Rep counts are the `ROUNDS` / `TRIALS` constants at the top of each file.

## Marketing language guardrail

Describe these as cognitive drills inspired by sports-science research on
anticipation, awareness, and reaction training. Do not cite IntelliGym's
study results (42% PPG, injury reduction) as outcomes of RinkReads; those
findings apply to their validated protocol, not this implementation.
