The Gauntlet — every question clears all of it before it can post itself live

Deterministic gates run first (free, and they decide correctness). Agent gates run last (cheap before costly). A question dies at the cheapest gate it fails. The LLM only ever writes prose, so a wrong answer key is structurally impossible.

On fail = rework loop

A fail is not a dead end. The item is sent back with that gate's notes, reworked, and re-enters the gate. If the coaches shut it down, it goes back for work and then back up to the coaches. After a cap (about 3 rounds) it lands in the human-review queue. Nothing is silently dropped.

Always-on backstops

  • Golden tests (CI): the solver's hand-labeled scenarios must stay green, or the whole gauntlet pauses. Currently 4/4.
  • Curriculum tag: every shipped item is tied to a concept node, so you can always answer "why is this here?"
  • Live feedback: a "report this read" button + an answer-disagreement monitor auto-flags suspects in production.
  • Spot-check: a random sample of each auto-posted batch is surfaced for a human glance.
