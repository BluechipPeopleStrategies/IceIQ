Cleared the whole gauntlet → lands in the review queue. You open #review, see it rendered exactly as a kid would, and Approve → bank.json (live). The proxy gate slots in here later.

REWORK LOOP

Any gate that says REVISE / not-unanimous / KICK BACK sends the question back to the Creator with the specific critique, to regenerate. Capped at --rounds 3.

A miss isn't a discard — it's a revise-and-resubmit, like real coaching.

DROP + LEARN

If it still can't reach the bar after the cap, it is dropped (logged, never shipped). A lesson-extractor distills the failure into 1–2 general rules.

Rules accumulate in lessons.json and are injected into every future Creator prompt → the generator stops repeating the same mistakes.

↑ feeds back into G0 — the self-improving loop

Real example (live run)

A U9 lead-pass question was dropped: the perfectionist found the stem pre-committed to “you decide to pass” while still offering a “shoot” option, and the other coaches conceded. Lessons learned:

Never let the stem pre-commit to a decision while offering options that contradict it.

Distractors must cover distinct error dimensions (lane AND timing), not the same mistake twice.

Run it

npm run gauntlet -- --node u9.passing

npm run gauntlet -- --fill-gaps --max 10

Default = full panel + Head Coach. --fast = single coach. --mock = no-cost dry run.
