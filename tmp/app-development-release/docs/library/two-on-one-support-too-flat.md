# 2-on-1: Support Too Flat

## Teaching Point

A 2-on-1 is not automatically a pass.

If the support player is too flat or not in a dangerous scoring lane, the puck carrier should not force the pass.

## Main Cue

Support is available but not dangerous.

## Correct Read

Attack the open shot lane or keep the attack.

## Common Mistake

Passing because it is a 2-on-1, even though the teammate is not actually in a useful scoring position.
