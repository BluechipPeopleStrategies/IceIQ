7Coverage AuditMEASURE
Counts live questions per ledger node vs the ~860 target, then tells the generator what's still thin — closing the loop back to steps 1–2.
npm run audit:curriculum
Coverage loop (7 → 2): the audit feeds the generator which nodes are under target, so --fill-gaps always works on what's missing.

Learning loop (2 → 2): every dropped question writes a rule into lessons.json that goes into the next creator prompt, so quality compounds.
