# RinkReads Brain Gym

## Overview
The Brain Gym (`src/cognitive-gym/`) is a set of procedurally generated
brain-training games for youth hockey players (U7 to U18): anticipation,
awareness, reaction, and more. Every rep is generated by code, so there is zero
content to maintain. Games inspired by sports-cognition tools (anticipation,
multi-object tracking, go/no-go, perception span, peripheral vision) but built
original.

**Core principle:** these are *real reads*, fun, and honest. A game must train a
skill that shows up on the ice, reward genuine precision, and never lie to the
player about how they did.

This skill is the living source of truth for how the games behave. When Thomas
gives a new rule, add it to "Rules from Thomas" below and apply it everywhere it
fits. Read this before touching any game.

Restart, resize re-fit) is proven across all of these.

## Non-negotiable rules
1. **Procedural, not authored.** Every rep is generated by code. No hand-written
   content banks for a game.
2. **Pure logic is testable.** Scoring, leveling, and generators go in pure
   modules (`gymPoints.js`, `<name>Core.js`, `gymEngine.js`) with tests in
   `scripts/test-gym.mjs`. Render loops are play-tested, not unit-tested.
3. **Points and leveling are decoupled.** Leveling runs off a binary success
   flag (inside a small success window). Points are a separate graded reward.
   See "Rules from Thomas" for the current scoring and leveling laws.
4. **Voice.** Player-facing copy is warm, growth-oriented, kid-friendly, and
   sounds like Thomas. No em dashes; use commas, periods, parentheses.
5. **Accessibility.** Never rely on color alone. Pair every color signal with a
   shape, icon, or label (red/green is off-limits as the only cue).
6. **Marketing guardrail.** Describe games as inspired by sports-cognition
   research. Never use IntelliGym / NeuroTracker / Velocity / Senaptec branding
   or cite their validated study results as RinkReads outcomes.
7. **Fit the screen.** The whole rink must always be visible while playing. See
   the sizing rule below.

## How to add or change a game (pattern)
1. Read this skill + the spec + the plan.
2. Pure logic first: generator and/or scoring in a `<name>Core.js`, with tests
   in `scripts/test-gym.mjs`. Run `npm run test:gym` green before UI.
3. Component: follow the `intro / playing / done` phase pattern of the existing
   drills. Intro leads with a **"Your goal:"** line, then "The game:" mechanics,
   then a "Why it matters" hockey block.
4. Register it in `DRILLS` with `{ id, name, skill, blurb, goal, why, build, component }`
   (`build` is `'canvas'` or `'rink'`).
5. Drive difficulty with `levelT(level)` + `lerp(easy, hard, t)`.
6. Use the shared adaptive level (`createAdaptiveLevel`) and persist via
   `saveSession` (`{ score, points, level, streak }`).
7. Play-test in the running dev server.

## Rules from Thomas (living — obey these; append new ones with a date)

### 2026-06-13
- **Read the Pass travels all four directions.** Left-to-right, right-to-left,
  top-to-bottom, bottom-to-top. Not just horizontal. The gold bar sits on the
  exit edge; the guess runs along that edge. (done)
- **Bigger gold bar.** The crossing target is a thick gold band, not a thin
  line, so there is more area to aim at. (done, `BAR` constant)
- **Much smaller success window.** The tolerance for a "hit" (which drives
  leveling) is tight. Precision matters. (done, `tolerance` shrunk)
- **GeoGuessr-style graded points.** Closer to the exact spot is worth more.
  Bang-on beats barely-right even when both are inside the success circle.
  Exact = max points, smooth exponential decay with distance. (`gymPoints.js`)
- **A points system across the whole gym.** Track points earned per rep and
  per session, and a career-points total on the hub, based on how well the
  player actually performs.
- **Coherent, logical leveling for every game.** One unified rule: you earn
  your way up (a streak of successes promotes you) and you can be relegated (a
  streak of failures drops you). Progress persists across sessions and is
  visible ("N to level up"). Same thresholds in every game so a level means the
  same thing everywhere.
- **Fit the rink to the screen.** On desktop the whole rink must stay visible
  while you follow the play; never size it so big it runs off-screen. Cap the
  canvas to the viewport (and a sane max width). Resizing the window must
  re-fit and rescale the play, never skip to the next rep. (done in
  `gymEngine.setupCanvas` + `TrackingDrill` resize handler)
- **Score in real distance, the same in every direction.** Don't normalize a
  miss by the on-screen pixel span of the guess axis — that made top/bottom
  passes far more forgiving than left/right (different axis lengths). Convert
  the pixel miss to REAL feet on a regulation rink (200 ft long x 85 ft wide)
  using `feetPerPixel`, and base both the success window and the points on feet
  so a 5 ft miss scores the same whichever way the puck came. (done in
  `anticipationCore.js`)
- **Distances must be a real measurement, not a bare number.** Tell the player
  how close they were in feet (or meters), e.g. "off by 3.2 ft" / "bang on",
  not just "+872". Keep a points total too. (done, `formatDistance`)
- **Let the player choose feet or meters.** Unit is a persisted gym-wide
  preference (`getUnit`/`setUnit`, default feet), toggleable in the game.
- **Signal quality clearly; make "Perfect" hard.** Don't use vague praise like
  "bang on". Show a quality tier (Perfect > Great read > On target > Missed) plus
  the real distance, so the player always knows how good a read was. "Perfect"
  is a tiny window (`PERFECT_FT`, ~half a foot) so it stays rare and earned, and
  the exact crossing is drawn as a gold dot so what counts as perfect is visible.
  (done, `rateMiss` + target dot)
- **Show the game name at the top.** During play and on the results screen, the
  game's name sits at the top (`.gym-drill-title`), not just on the intro card.
- **Hold the result long enough to learn from it.** After a rep, freeze the
  marked-up result (where you guessed vs the true spot, who you missed) long
  enough to study it before the next rep. Read the Pass ~2.4s, Head on a Swivel
  ~2.8s (`REVEAL_HOLD_MS` / `FEEDBACK_HOLD_MS`). Reaction stays fast on purpose.
- **Always offer Restart.** Every game has a Restart in the bar during play that
  starts the session over with fresh reps (calls the drill's `start()`).
- **Don't auto-run; start when ready.** A round must not begin on a timer the
  moment the screen loads. The player triggers each round (Head on a Swivel has
  a "ready" stage with a Start shift button before the gold flash). Nothing
  flashes until they say go.
- **Explain the level logic in-game.** Show a guide (Head on a Swivel: a left
  aside) that spells out how leveling works: all targets right = a success, 3
  successes in a row = level up, 2 misses = level down, higher levels add more
  difficulty. Leveling is success-based and the streak persists across sessions.
- **Difficulty must climb meaningfully.** Higher levels get genuinely harder,
  not marginally. Head on a Swivel: 5 -> 16 skaters, faster movement, longer
  tracking, and a shorter look at the targets.
- **Show the per-round result.** Tell the player how they did each round (Head
  on a Swivel: "You got X of 3 right" during the result hold), not just the
  session total.
- **Soccer-ball bonus (Baylor's Pick).** One of the three teammates carries a
  soccer ball (⚽), shown only while memorizing (hidden once they move), so you
  must track that specific teammate. To CALL it, double-tap that pick: the dot
  turns gold to flag the second tap. Picks no longer auto-resolve; tap your
  three then Lock in. Bonus only if your double-tapped call is the real carrier.
- **Naming / mascots.** The tracking game is "Baylor's Pick" (the player picks
  the tracked teammates). A bunny 🐰 and bear 🐻 are prominent mascots at center
  ice (bigger/brighter but drawn BEHIND the skaters so they never block play).
  Keep the storage id "tracking" so saved progress is preserved.
- **Rich hub stats.** The hub shows a wrapping stat board: day streak, best
  streak, sessions, days trained, career points, best session, top level,
  fastest reaction (ms). Add more as new games create new measurable things.
- **Illustrated intros.** Every game intro opens with a small illustration
  (inline SVG, on-brand colors) above the text, so the start is not all words.
- **Deselect a pick (Baylor's Pick).** Single-tap one of your picks to remove it
  and pick again; double-tap it (within ~350ms) to call it the soccer ball. The
  single-tap deselect is delayed briefly so a double-tap is not misread.
- **Realistic rink.** `drawRink` renders a real-looking sheet: rounded boards
  with a lighter glass line, two blue lines, red center line + circle, four
  end-zone faceoff circles with dots, goal lines, and blue creases. All canvas
  games share it.
- **In-ice title watermark.** The game title also sits faintly across the top of
  the rink itself (transparent), in addition to the heading above it.

### 2026-06-13 (pricing redesign + young-age session)
- **Focus U7 / U9 / U11 for now.** U13-U18 are paused: build, tune, and scope new
  gym work for the three young bands. The product still spans U7-U18; this is a
  current focus, not a removal.
- **New game: Pick Your Spot (id `shootout`).** Read the goalie and tap the open
  part of the net before he covers it. A 3x2 grid of tap cells; the goalie covers
  some at the start (saves) and more cells close mid-shot. Pure `shootoutCore.js`
  (params, cell geometry, deterministic `makeShot`, `scoreShot`), tested in
  `scripts/test-shootout.mjs`. An always-open invariant guarantees a scorable cell
  every shot. (done, shipped)
- **Difficulty may accelerate, not just rise linearly.** Where it fits, ramp the
  hard end harder using a non-linear curve, e.g.
  `lerp(easy, hard, Math.pow(levelT(level), 1.5))`. Pick Your Spot uses this so the
  open holes close faster (the goalie "gets bigger faster") the higher you climb.
  (done in `shootoutCore.holeOpenMs`)
- **Smarter start (calibration), not level 1 every time.** Seed a kid's starting
  level by age band (U7 low, U9 mid-low, U11 mid) and run a fast first-session
  placement (bigger up-steps) so a strong kid reaches their real level quickly.
  (spec'd, not built; see the progression spec)
- **Incentives layer.** Mastery stars per game, a gym-wide XP/rank, a daily goal +
  streak ring, and badges (including a few surprise/variable ones). No real-money
  currency, no loot boxes. (spec'd, not built)
- **Competition is age- and tier-gated.** Beat-your-best is free for all ages.
  Head-to-head challenge links (seeded so both runs are identical and fair) and
  promotion *leagues* (not raw global rankings, which stress young kids) are the
  Pro tier's competitive layer and lean gentle for the youngest. (spec'd, not
  built; ties to the pricing redesign in

## Common mistakes
- Sizing a canvas to container width only (overflows on desktop). Use the
  viewport-capped `setupCanvas`.
- Binary hit/miss scoring when the rule calls for graded points. Use
  `gradedPoints`.
- Letting leveling reset every session. Seed the streak from storage.
- Color-only feedback (blue/orange) without a shape or label.
- Em dashes in copy.
